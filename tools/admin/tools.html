本地服务与安全

监听 127.0.0.1，只有本机能访问；端口用 --port 改。

令牌每次启动随机生成并注入页面，写操作都要带 X-Admin-Token；同源校验 + 不返回 CORS 头，别的网站调不动。

Markdown 读写限定在 blogs/<编号>/ 目录内，拒绝路径穿越。

管理台不会自动发布，改完请自行 git commit 与推送。

对应命令

node tools/manage.js list

node tools/manage.js update <id> <md>

node tools/manage.js column list

node tools/add-article.js --sync-feeds
